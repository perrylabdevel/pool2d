# Audio Assets Directory

This directory contains sound effect samples for the pool game.

## Required Audio Files

Download these files from https://directory.audio/collection/77-billiard-sounds (CC0 License)

### Ball Collisions (3 files)
- `ball-collision-light.wav` - Light ball impact (low intensity)
- `ball-collision-medium.wav` - Medium ball impact
- `ball-collision-hard.wav` - Hard ball impact (break shot)

### Cue Hits (2 files)
- `cue-hit-1.wav` - Cue striking ball variation 1
- `cue-hit-2.wav` - Cue striking ball variation 2

### Rail Hits (2 files)
- `rail-hit-1.wav` - Ball hitting cushion variation 1
- `rail-hit-2.wav` - Ball hitting cushion variation 2

### Pocket Drops (1 file)
- `pocket-drop.wav` - Ball falling into pocket

## File Format Requirements
- **Format**: WAV (preferred) or MP3
- **Sample Rate**: 44.1kHz or 48kHz
- **Bit Depth**: 16-bit or 24-bit
- **Channels**: Mono or Stereo

## Download Instructions
1. Visit https://directory.audio/collection/77-billiard-sounds
2. Browse the collection for sounds matching the descriptions above
3. Download in WAV format when available
4. Rename files to match the names listed above
5. Place all files in this directory
