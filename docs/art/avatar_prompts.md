# AI Opponent Avatar Prompts

These prompts are designed to generate stylized character portraits for the AI opponents in RailRush. They follow a consistent mobile game art style.

## Global Style Settings
**Style:** Miniclip-style 2D vector art, bold thick outlines, vibrant saturated colors, premium mobile game aesthetic, rounded square (squircle) composition, close-up head and shoulders portrait, dynamic lighting, clean vector look.
**Negative Prompt:** text, watermark, logo, letters, numbers, realistic, photo, noise, grain, messy, sketch, rough, low poly, pixelated, blurry, full body, distant shot.
**Aspect Ratio:** 1:1
