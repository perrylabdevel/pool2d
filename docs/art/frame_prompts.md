# Avatar Frame Prompts

These prompts are designed to generate consistent avatar frames for the "RailRush" mobile game. They follow the "Standard Squircle + Gem Holder" design pattern requested by the user.

## Global Style Settings
**Style:** Mobile Game UI, Vector Art, Clean, Metallic, Rounded Square (Squircle), Bottom Center Gem Holder.
**Negative Prompt:** text, watermark, logo, letters, numbers, realistic, photo, noise, grain, messy, sketch, rough, low poly, pixelated, blurry, full body, distant shot, asymmetrical, complex background.
**Aspect Ratio:** 1:1

---

## Bronze League
**Prompt:**
A square avatar frame for a mobile game UI. The frame is a clean, metallic border with rounded corners (squircle). It has a 'Bronze' theme with a brushed bronze metal texture. There is a decorative 'gem holder' socket at the bottom center containing a bronze-colored gem or emblem. The center is transparent (alpha channel) for the avatar. High quality, vector style, game asset. No text. Isolated on black background.
